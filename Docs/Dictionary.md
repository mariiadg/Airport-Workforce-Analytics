# Словарь

## Авиационные термины и термины проекта

| Термин | Расшифровка |
|---|---|
| **DCS** (Departure Control System) | Система регистрации. Используется для регистрации пассажиров, посадки, оформления багажа |
| **Basic / Medium / Expert DCS** | Уровни сложности систем регистрации |
| **Check-in (регистрация)** | Процедура оформления пассажира на рейс: проверка документов, выдача посадочного талона, приём багажа |
| **Boarding (посадка)** | Процедура посадки пассажира в ВС через выход на посадку |
| **ВС** | Воздушное судно |
| **Wide-body (широкофюзеляжный ВС)** | Крупный пассажирский самолет с широким корпусом (диаметром от 5 метров и более), в салоне которого предусмотрено два или более прохода между рядами кресел. Регистрация начинается за 4 часа до вылета, требует 2 комплекта сопроводительных документов |
| **Narrow-body (узкофюзеляжный ВС)** | Самолет с одним проходом между рядами кресел и шириной салона менее 4 метров |
| **Стойка регистрации** | Рабочее место агента, где происходит регистрация |
| **Наложение (конфликт) стоек** | Ситуация, когда два рейса регистрируются на одной стойке в одно время |
| **Международный рейс** | Рейс за пределы страны. Требует пограничного и таможенного контроля |
| **Внутренний рейс** | Рейс внутри страны |
| **ПВТР** | Правила внутреннего трудового распорядка. В проекте используется норматив из ПВТР: 1 агент на 50 пассажиров |
| **Regular agent** | Агент основного состава смены |
| **Extra agent** | Дополнительный агент, привлекаемый из другой смены |
| **Intern (стажёр)** | Агент на обучении. Работает под контролем |
| **Senior agent** | Опытный агент с расширенными допусками |
| **Supervisor** | Начальник смены |
| **Shift (смена)** | Рабочий период длиной 12 часов. Дневная либо ночная смена |
| **Перерыв (break)** | Время между закрытием регистрации предыдущего рейса и началом следующего в рамках одной смены |
